# التثبيت على جهاز جديد

الأداة تعمل على ويندوز 10 أو 11. كل المعالجة تجري على الجهاز نفسه، والإنترنت يلزم للتثبيت، ولتنزيل نص الكتاب من turath.io، ولتنزيل نموذج التفريغ في أول تشغيل.

## المتطلبات

| المطلوب | لماذا |
|---|---|
| Python 3.11 أو أحدث (جُرّبت على 3.13) | لغة الأداة |
| ffmpeg و ffprobe في مسار النظام | قراءة التسجيلات وتحويلها وصنع المعاينة |
| نحو 4 غيغابايت فارغة | المكتبات ونموذج التفريغ (نحو 1.6 غيغابايت) |
| ذاكرة 8 غيغابايت أو أكثر (جُرّبت على 16) | التفريغ الصوتي |
| اللغة العربية مضافة في ويندوز | لقراءة الكتب التي لا نص لها فقط |
| DaVinci Resolve (المجانية تكفي) | لفتح الخط الزمني الناتج |

## الخطوات

### 1. Python
نزّله من <https://www.python.org/downloads/> وفعّل في المثبِّت خيار «Add python.exe to PATH».

### 2. ffmpeg
في نافذة PowerShell:

```powershell
winget install Gyan.FFmpeg
```

ثم أغلق النافذة وافتح أخرى وتحقق:

```powershell
ffmpeg -version
```

إن لم يتوفر `winget` فنزّل ffmpeg من <https://www.gyan.dev/ffmpeg/builds/>، وفك ضغطه، وأضف مجلد `bin` إلى متغير البيئة `Path`.

### 3. الأداة

```powershell
git clone https://github.com/hamza-nahhas/majlis-cut.git
cd majlis-cut
```

أو نزّل المستودع ملفًّا مضغوطًا من صفحة GitHub وفكّه. يُفضَّل مسار قصير بلا حروف عربية، مثل `D:\majlis-cut`.

### 4. الإعداد
انقر مرتين على `setup.bat`. ينشئ بيئة Python خاصة بالأداة في مجلد `.venv` ويثبّت المكتبات فيها. يستغرق بضع دقائق.

### 5. التشغيل
انقر مرتين على `start.bat`. تفتح الواجهة في المتصفح على العنوان `http://127.0.0.1:8765`.

في أول درس يُنزَّل نموذج التفريغ `large-v3-turbo` (نحو 1.6 غيغابايت) مرة واحدة، ويُحفظ في مجلد المستخدم (`.cache\huggingface`).

## اللغة العربية لقراءة الصفحات

تلزم فقط للكتب غير الموجودة في turath.io. من إعدادات ويندوز: الوقت واللغة ← اللغة والمنطقة ← إضافة لغة ← العربية. للتحقق، في PowerShell:

```powershell
[void][Windows.Media.Ocr.OcrEngine,Windows.Foundation,ContentType=WindowsRuntime]
[Windows.Media.Ocr.OcrEngine]::AvailableRecognizerLanguages | % LanguageTag
```

يجب أن يظهر في القائمة سطر يبدأ بـ`ar`.

## التحديث

```powershell
git pull
```

ثم شغّل `setup.bat` مرة أخرى إن تغيّر ملف `requirements.txt`.
