# دليل الاستعمال

## ما تحتاجه لكل درس

| الملف | ملاحظات |
|---|---|
| **تسجيل الدرس** | الملف الصوتي الرئيسي المتصل (صوت القارئ والمعلّق معًا)، وهو صوت الفيديو النهائي. أو فيديو جاهز للدرس كله. |
| **ملف الكتاب PDF** | مصوَّر. مجلد كامل، أو القسم المقروء فقط. |
| **مقاطع الكاميرا الأساسية** (اختياري) | مقاطع الـ20–30 دقيقة كما خرجت من الكاميرا. |
| **مقاطع كاميرا الاحتياط** (اختياري) | تُستعمل في فجوات الأساسية فقط. |
| **صورة الخلفية** (اختياري) | تصميمكم الذي توضع عليه صفحة الكتاب، بمقاس 1920×1080. |

## الحالات الثلاث

1. **صوت وكاميرات:** الأداة تزامن المقاطع مع الصوت وتضعها في أماكنها.
2. **صوت فقط:** يخرج الخط الزمني بالصوت وصور الصفحات، ومكان الكاميرا فارغ تملؤه في Resolve.
3. **فيديو جاهز:** اختر الفيديو في خانة «تسجيل الدرس» ولا تضف كاميرات. يوضع الفيديو في المسار V1 وتُضاف فوقه صفحات الكتاب.

## الخطوات في الواجهة

شغّل `start.bat` وأبقِ نافذته مفتوحة. الواجهة تحفظ آخر اختياراتك.

### 1. الملفات
اختر تسجيل الدرس. يُقترح مجلد الدرس تلقائيًّا بجانب التسجيل (باسمه مع `_montage`). أضف مقاطع الكاميرتين إن وُجدت.

### 2. الكتاب
اختر ملف الـPDF، ثم مصدر النص:

- **من مكتبة تراث (الأدق):** ابحث باسم الكتاب واختر الطبعة التي توافق ملفك، ثم المجلد. يُفحص فرق ترقيم الصفحات تلقائيًّا، وتظهر صورة الصفحة بجانب نصها. يجب أن يتطابقا. إن لم يتطابقا فالطبعة غير الطبعة، أو الفرق يحتاج تعديلًا يدويًّا.
- **من ملف الـPDF نفسه:** للكتب غير الموجودة في المكتبة. لا تختار كتابًا ولا مجلدًا ولا ترقيمًا. زر «معاينة» يعرض ما قُرئ من الصفحة.

«حصر الصفحات» اختياري (مثل `1-120`)، ويفيد حين يتكرر النص نفسه في مواضع متباعدة من الكتاب، أو لاختصار قراءة ملف كبير.

### 3. الشكل
- **مقدار الصفحة الظاهر:** 0.55 يعني نصف صفحة تقريبًا.
- **الخلفية:** صورة تصميمكم.
- **حجم بطاقة الصفحة وموضعها.**

المعاينة على اليمين تتغير فور تعديل أي إعداد.

### 4. التشغيل
راجع الملخص واضغط «تشغيل». المراحل:

1. تفريغ الصوت (الأطول: نحو 40% من مدة الدرس، ويُحفظ فلا يُعاد)
2. قراءة الكتاب
3. مطابقة التسجيل مع الكتاب
4. مزامنة الكاميرات
5. تجهيز صور الصفحات
6. كتابة الخط الزمني
7. صنع المعاينة

يمكن إيقاف التشغيل. إن أُوقف أثناء التفريغ يُستأنف من حيث توقف.

### 5. المراجعة
- **الأرقام:** مدة القراءة وعدد مقاطعها.
- **الملاحظات:** ما يستحق النظر (انظر [حل المشكلات](TROUBLESHOOTING.md)). النقر على ملاحظة ينقل الفيديو إلى موضعها.
- **المعاينة:** فيديو منخفض الجودة للتحقق السريع.
- **قائمة المقاطع:** النقر على مقطع ينقل الفيديو إليه.

## التصحيح

مرّر على مقطع واضغط «← كاميرا» أو «← كتاب» لقلبه. التصحيحات تتراكم، ثم «تطبيق التصحيحات» يعيد كتابة الخط الزمني والمعاينة في ثوانٍ دون إعادة التفريغ. المقطع المصحَّح يحمل زر «تراجع»، و«إلغاء كل التصحيحات» يعيد النتيجة الآلية.

التصحيحات تُحفظ في `work\edits.json` وتبقى عند إعادة التشغيل.

## الاستيراد في DaVinci Resolve

1. افتح مشروعًا جديدًا.
2. File ← Import ← Timeline.
3. اختر `resolve\timeline.xml` من مجلد الدرس (زر «نسخ المسار» في الواجهة).
4. اقبل إعدادات المشروع المقترحة.

| المسار | ما فيه |
|---|---|
| V1 | الكاميرات (أو الفيديو الجاهز) |
| V2 | صور الصفحات، كل صورة بمدتها |
| A1 و A2 | صوت الدرس |

كل شيء قابل للتعديل: حرّك أطراف الصور، احذف، أضف انتقالات. الصور إطارات كاملة 1920×1080 (الصفحة على الخلفية)، فتغطي الكاميرا تمامًا حين تظهر.

**إن أعدت التشغيل بعد الاستيراد** فاستورد `timeline.xml` من جديد: الخط الزمني المستورد سابقًا لا يتحدث وحده.

## مجلد الدرس

```
<مجلد الدرس>\
  resolve\   timeline.xml، صور الصفحات (pages)، lesson_audio.wav، lesson_video.mov
  review\    preview.mp4 و report.txt
  work\      التفريغ والخطة والتصحيحات (ملفات الأداة)
```

لنقل العمل إلى جهاز آخر انقل مجلد `resolve` كاملًا. إن تغيّر مساره فسيطلب Resolve إعادة ربط الملفات.

بجانب مجلدات الدروس ينشأ مجلد `_books` (عند التشغيل من سطر الأوامر) أو `cache` داخل مجلد الأداة (عند التشغيل من الواجهة): فيه نصوص الكتب المنزَّلة وما قُرئ من ملفات الـPDF.

## سطر الأوامر

```powershell
cd D:\majalis_pro_editor
.venv\Scripts\python.exe -m darsmontage `
  --audio "D:\lesson\lesson02.mp3" `
  --pdf "D:\lesson\book_vol3.pdf" `
  --turath 197 --vol 3 `
  --cam-main "D:\lesson\cam_main" `
  --cam-backup "D:\lesson\cam_backup" `
  --out "D:\lesson\out02"
```

| الخيار | معناه |
|---|---|
| `--audio` | تسجيل الدرس (صوت أو فيديو جاهز) |
| `--pdf` | ملف الكتاب |
| `--out` | مجلد الدرس |
| `--turath` و `--vol` | رقم الكتاب في turath.io والمجلد. بدون `--turath` يُقرأ النص من الـPDF |
| `--page-offset` | رقم صفحة الـPDF ناقص الرقم المطبوع (الافتراضي 0) |
| `--pages 1-120` | حصر الصفحات |
| `--window 0.55` | مقدار الصفحة الظاهر |
| `--background` | صورة الخلفية |
| `--overlay-size` و `--overlay-pos` | حجم بطاقة الصفحة (نسبة من ارتفاع الإطار) وموضعها: `left` أو `center` أو `right` |
| `--cam-main` و `--cam-backup` | مقاطع الكاميرتين: مجلدات أو ملفات |
| `--fps` | معدل الإطارات حين لا توجد كاميرات (الافتراضي 25) |
| `--asr` | `whisper` (محلي) أو `elevenlabs` (بمفتاح `ELEVENLABS_API_KEY`) |
| `--cache` | مجلد نصوص الكتب المحفوظة |
| `--no-preview` | بلا فيديو معاينة |

رقم الكتاب في turath.io هو الرقم في آخر عنوان صفحته، مثل `https://app.turath.io/book/197`.
